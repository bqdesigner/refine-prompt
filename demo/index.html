4. Shadow DOM

O widget abaixo vive num shadow root aberto. O tooltip precisa mostrar o elemento de dentro, e o prompt precisa avisar que o seletor não alcança de fora.

5. Camadas que não recebem clique

  • O rodapé escuro no canto de baixo tem pointer-events: none (e os links dentro dele, não). Ele precisa ser selecionável - era o bug que falhava calado.
  • O toast "Proposta salva" mora numa camada que cobre a tela inteira. Passar o mouse no meio da página precisa continuar pegando o conteúdo, não a camada. Alt cicla para alcançá-la.
  • O cabeçalho fixo não pode ficar embaixo do painel: o side panel nativo encolhe a viewport de verdade.

6. Sessão entre páginas

Ligue "Seguir navegação", comente aqui, vá para outra página e comente de novo: o prompt sai com as duas, separadas por página.
